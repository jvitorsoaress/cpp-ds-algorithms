# Data Structures & Algorithms Problems

This repository contains my solutions to coding and algorithmic problems from various platforms, mostly written in Python for its concise and expressive syntax.

It serves as a personal collection of problems I've solved while studying data structures, algorithms, problem-solving techniques, and programming fundamentals.

## Structure

The repository is organized by platform:

* **HackerRank** — Solutions to coding challenges from [HackerRank](https://www.hackerrank.com/).
* **LeetCode** — Solutions to problems from [LeetCode](https://leetcode.com/).
* **URI / Beecrowd** — Solutions to programming challenges from [Beecrowd](https://www.beecrowd.com.br/).

## Purpose

* Practice and improve problem-solving skills.
* Study data structures and algorithms through practical problems.
* Track my progress and keep a reference of problems I've solved.
* Explore different approaches and improve code quality and efficiency.
